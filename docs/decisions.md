# Decisiones del proyecto

- GitHub concentra código y contexto versionado; Supabase conserva datos privados. Los chats no se sincronizan con Git.
- Mantener Next.js/React/Supabase actuales; no migrar stack para resolver tareas pequeñas.
- UI en español, compacta, consistente; cambios de estructura importantes pasan primero por propuesta visual.
- Sin API de IA paga como requisito del MVP. PDF.js y reglas producen borradores, no inferencias garantizadas.
- Afinidad profesional y condiciones laborales se muestran por separado. Ninguna representa probabilidad de contratación.
- Enriquecer avisos no modifica decisiones del CRM. Conservar descartados.
- Job Match es una automatización externa con herramientas autorizadas, no un cron incorporado en Vercel.
- No almacenar datos personales de muestra, exportaciones privadas ni credenciales en Git.
- Documentar nuevas decisiones con fecha, motivo, alcance y consecuencias; no convertir propuestas de roadmap en decisiones aprobadas.
